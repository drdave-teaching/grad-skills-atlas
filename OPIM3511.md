# OPIM 3511 — Skills Atlas (Business Data Analytics II)

### *ML Fundamentals — from scratch and with scikit-learn* · undergraduate

*What you'll be able to do — each skill paired with its theory, its real-world implementation, and **how to practice it**. Taught in **Python / Google Colab**.*

**Legend:** ✋ **by hand** (math/manual) · 💻 **local code** (a notebook) · ☁️ **production** (deployed in the cloud)

**Learning objectives:** ①wrangle dirty data & run a structured **EDA** ②fit, scale, split & **evaluate** models honestly ③build **trees, forests & boosting from scratch**, then implement them ④handle **imbalanced data** (SMOTE) ⑤**interpret** models and productionize with pipelines

---

## In one sentence
By the end, **you can take a messy data set, engineer features, and build every core ML algorithm — trees, forests, and boosting — by hand *and* with scikit-learn, then honestly evaluate and explain it.** The philosophy: build it from scratch first, so the library is a power tool, not a black box.

## In the curriculum
3511 is the capstone of the **undergraduate BDA (BS) core** (3505 → 3510 → **3511**). Officially it maps to the graduate **Predictive Modeling** requirement — OPIM **5604** may substitute for 3511 — and it shares a heavy modeling core with graduate **5512** *Data Science using Python* (same ML methodology, trees, SMOTE, cross-validation, pipelines, xAI, AutoML). Master this, and the graduate courses layer on production + cloud (5512), deep learning (5509), and the frontier (5516). The from-scratch trees/boosting here are the theory beneath deep-learning gradients, and the interpretation toolkit (permutation, PDP, Boruta) is identical across 3511/5512/5516.
